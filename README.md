# 🎓 SQL Learning Management System (LMS)

## 📌 Project Overview
This project demonstrates the design and implementation of a Learning Management System (LMS) database using Microsoft SQL Server. It models the core operations of an LMS, including student management, courses, batches, trainers, enrollments, attendance, fees, assessments, and placements.

---

## 🎯 Objectives
- Design a normalized relational database.
- Implement Primary Keys and Foreign Keys.
- Enforce data integrity using constraints.
- Build a scalable database structure for an LMS.

---

## 🛠️ Tools & Technologies

- SQL
- Relational Database Design

## ✨ Features
- Normalized database schema
- Primary Key & Foreign Key relationships
- Constraints for data integrity
- Multiple interconnected tables
- Ready for reporting and analytics
